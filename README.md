# Spectacly

Single-page marketing site for Spectacly, a 3D property scanning service. Physical spaces are captured and converted into interactive, browser-based walkthroughs. Quote-based pricing.

## Stack

Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```
